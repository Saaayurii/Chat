🚀 Тест Chat Widget

Этот файл тестирует работу чат-виджета.

✅ Виджет должен появиться в правом нижнем углу экрана

Инструкция для тестирования:

  1. Убедитесь, что backend API запущен на http://localhost:3004
  2. Найдите синюю кнопку чата в правом нижнем углу
  3. Нажмите на кнопку для открытия виджета
  4. Попробуйте отправить сообщение
  5. Проверьте работу всех функций (файлы, рейтинги, жалобы)

Конфигурация:

  • API URL: http://localhost:3004
  • Тема: светлая
  • Позиция: правый нижний угол
  • Цвет: #3b82f6
