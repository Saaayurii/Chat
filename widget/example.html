🎯 Пример встраивания Chat Widget

Этот виджет создан с помощью Vite + React + TypeScript + Tailwind + Zustand и готов для встраивания на любой сайт.

📋 Особенности виджета:

  • ✅ JWT аутентификация + анонимные сессии
  • ✅ Real-time WebSocket подключение
  • ✅ Загрузка истории сообщений
  • ✅ Система рейтингов и жалоб
  • ✅ Загрузка файлов
  • ✅ Адаптивный дизайн
  • ✅ Настраиваемые темы и цвета

🚀 Конфигурация виджета:

Текущие настройки:

API URL: http://localhost:3004
Тема: Светлая
Позиция: Правый нижний угол
Основной цвет: #3b82f6
Загрузка файлов: Разрешена
Жалобы: Разрешены
Рейтинги: Разрешены

📝 Как встроить на сайт:

1. Подключите CSS и JS файлы:

<!-- CSS виджета -->
<link rel="stylesheet" href="./dist/ChatWidget-BkN3Fr8E.css">

<!-- Основной JS файл -->
<script src="./dist/ChatWidget-DjGfgXU6.js"></script>

<!-- Инициализатор виджета -->
<script src="./dist/chat-widget.js"></script>

2. Инициализируйте виджет:

<script>
window.initChatWidget({
    apiUrl: 'http://localhost:3004',
    theme: 'light',
    position: 'bottom-right',
    primaryColor: '#3b82f6',
    allowFileUpload: true,
    allowComplaint: true,
    allowRating: true,
    placeholder: 'Введите сообщение...',
    welcomeMessage: 'Добро пожаловать! Как могу помочь?',
    operatorName: 'Оператор поддержки'
});
</script>

⚙️ Доступные опции конфигурации:

interface ChatWidgetConfig {
  apiUrl?: string;              // URL API сервера (default: http://localhost:3004)
  theme?: 'light' | 'dark';     // Тема виджета (default: light)  
  position?: 'bottom-right' | 'bottom-left'; // Позиция (default: bottom-right)
  primaryColor?: string;        // Основной цвет (default: #3b82f6)
  allowFileUpload?: boolean;    // Разрешить загрузку файлов (default: true)
  allowComplaint?: boolean;     // Разрешить жалобы (default: true)
  allowRating?: boolean;        // Разрешить рейтинги (default: true)
  maxFileSize?: number;         // Макс размер файла в байтах (default: 10MB)
  placeholder?: string;         // Placeholder для поля ввода
  welcomeMessage?: string;      // Приветственное сообщение
  operatorName?: string;        // Имя оператора по умолчанию
  operatorAvatar?: string;      // Аватар оператора по умолчанию
  autoLoad?: boolean;           // Автозагрузка при инициализации (default: true)
  minimizeOnStart?: boolean;    // Свернуть при старте (default: false)
}

Виджет должен появиться в правом нижнем углу экрана. Нажмите на него, чтобы начать чат!
