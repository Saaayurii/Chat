# Комплекс тестирования чат-фронтенда

Это Next.js приложение теперь включает в себя комплексную систему тестирования Jest со следующими возможностями:

## 📋 Покрытие тестами

### ✅ UI Компоненты
- **Badge** - Варианты стилей, размеры и отображение содержимого
- **Input** - Обработка форм, валидация и взаимодействие с пользователем
- **Loading** - Различные размеры, темы и состояния загрузки
- **Modal** - Открытие/закрытие, навигация с клавиатуры и доступность
- **Pagination** - Навигация, расчеты страниц и граничные случаи

### ✅ Компоненты чат-виджета
- **ChatWidget** - Обмен сообщениями в реальном времени, загрузка файлов, система рейтингов
- **RatingModal** - Звездочные рейтинги, валидация форм и отправка
- **ComplaintModal** - Обработка форм, валидация и отправка

### ✅ Пользовательские хуки
- **useApiCall** - Обработка API запросов, состояния загрузки и управление ошибками
- **useFormState** - Управление состоянием форм, валидация и обработка полей
- **usePagination** - Логика пагинации, навигация и вычисления
- **useNotifications** - Уведомления-тосты с автоудалением и типами

### ✅ Компоненты управления
- **BlacklistManagement** - CRUD операции, поиск и пагинация
- **RatingForm** - Звездочные рейтинги, подробные отзывы и валидация

### ✅ Компоненты страниц
- **Админ страницы** - Чёрный список, жалобы и другие админские интерфейсы
- **Widget Demo** - Демонстрация и тестирование чат-виджета

## 🛠️ Настройка тестирования

### Файлы конфигурации
- `jest.config.ts` - Полная конфигурация Jest с интеграцией Next.js
- `src/test-utils/setup.ts` - Глобальная настройка тестов и моки
- `src/test-utils/index.ts` - Пользовательская функция рендеринга с провайдерами
- `src/test-utils/mocks.ts` - Фабрики мок-данных и API ответов

### Скрипты тестирования
```bash
# Запустить все тесты
npm test

# Запустить тесты в режиме наблюдения
npm run test:watch

# Запустить тесты с отчетом покрытия
npm run test:coverage

# Запустить тесты в CI среде
npm run test:ci
```

## 🔧 Конфигурация тестов

### Конфигурация Jest
- **Окружение**: jsdom для тестирования DOM
- **Файлы настройки**: Глобальные моки и утилиты тестирования
- **Маппинг модулей**: TypeScript алиасы путей
- **Покрытие**: Комплексная отчетность покрытия
- **Таймаут**: 10-секундный таймаут теста

### Библиотеки тестирования
- **Jest** - Фреймворк и раннер тестов
- **React Testing Library** - Утилиты тестирования компонентов
- **Jest DOM** - Матчеры утверждений DOM
- **User Event** - Симуляция взаимодействия с пользователем

## 📝 Написание тестов

### Тесты компонентов
```typescript
import { render, screen, fireEvent } from '@/test-utils';
import MyComponent from '../MyComponent';

describe('MyComponent', () => {
  it('рендерится корректно', () => {
    render(<MyComponent />);
    expect(screen.getByText('Привет')).toBeInTheDocument();
  });
});
```

### Тесты хуков
```typescript
import { renderHook, act } from '@testing-library/react';
import { useMyHook } from '../useMyHook';

describe('useMyHook', () => {
  it('возвращает ожидаемое значение', () => {
    const { result } = renderHook(() => useMyHook());
    expect(result.current.value).toBe('expected');
  });
});
```

## 🔍 Отчеты покрытия

Отчеты покрытия генерируются в директории `coverage/`:
- **HTML отчет** - Интерактивная визуализация покрытия
- **LCOV отчет** - Для CI/CD интеграции
- **Текстовый отчет** - Сводка в консоли

## 🚨 Устранение неполадок

### Общие проблемы
1. **Разрешение модулей** - Проверьте TypeScript алиасы путей
2. **Асинхронные операции** - Используйте правильные паттерны async/await
3. **Очистка DOM** - Тесты должны очищать за собой
4. **Персистентность моков** - Очищайте моки между тестами

### Советы по отладке
```bash
# Запустить конкретный тестовый файл
npm test -- MyComponent.test.tsx

# Запустить тесты с подробным выводом
npm test -- --verbose

# Отладить падающие тесты
npm test -- --detectOpenHandles
```
