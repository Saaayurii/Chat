🚀 Chat Widget - Пример встраивания

Демонстрация работы виджета чата на сайте

📋 Инструкция по встраиванию

Для встраивания виджета на ваш сайт выполните следующие шаги:

1. Базовое встраивание

Добавьте этот код перед закрывающим тегом </body>:

<script> (function() { // Конфигурация виджета window.chatWidgetConfig = { apiUrl: 'https://your-api-domain.com', theme: 'light', position: 'bottom-right', primaryColor: '#3b82f6', allowFileUpload: true, allowComplaint: true, allowRating: true, welcomeMessage: 'Добро пожаловать! Как могу помочь?', operatorName: 'Служба поддержки' }; // Загрузка стилей var link = document.createElement('link'); link.rel = 'stylesheet'; link.href = 'https://your-api-domain.com/chat-widget.css'; document.head.appendChild(link); // Загрузка скрипта var script = document.createElement('script'); script.src = 'https://your-api-domain.com/chat-widget.js'; script.async = true; document.body.appendChild(script); })(); </script>

2. Программная инициализация

Если вы хотите инициализировать виджет программно:

<script src="https://your-api-domain.com/chat-widget.js"></script> <link rel="stylesheet" href="https://your-api-domain.com/chat-widget.css"> <script> // Инициализация после загрузки window.addEventListener('load', function() { if (window.initChatWidget) { window.initChatWidget({ apiUrl: 'https://your-api-domain.com', theme: 'light', position: 'bottom-right', primaryColor: '#007bff', welcomeMessage: 'Здравствуйте! Чем могу помочь?' }); } }); </script>

⚙️ Параметры конфигурации

Параметр Тип Описание По умолчанию
apiUrl string URL API сервера http://localhost:3004
theme 'light' | 'dark' Тема виджета 'light'
position 'bottom-right' | 'bottom-left' Позиция виджета 'bottom-right'
primaryColor string Основной цвет виджета '#3b82f6'
allowFileUpload boolean Разрешить загрузку файлов true
allowComplaint boolean Разрешить отправку жалоб true
allowRating boolean Разрешить оценку операторов true
welcomeMessage string Приветственное сообщение 'Добро пожаловать!'
operatorName string Имя оператора по умолчанию 'Оператор'

🔧 Требования

  • Backend API: Убедитесь, что ваш backend API запущен и доступен
  • CORS: Настройте CORS для домена, где будет размещен виджет
  • HTTPS: Для продакшена рекомендуется использовать HTTPS
  • WebSocket: Убедитесь, что WebSocket подключения разрешены

📚 Дополнительная информация

  • Виджет автоматически определяет авторизованных пользователей
  • Анонимные пользователи получают временную сессию
  • История сообщений сохраняется между сеансами
  • Поддерживается загрузка файлов (до 10MB по умолчанию)
  • Встроенная система рейтингов и жалоб
