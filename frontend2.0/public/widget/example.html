🚀 Встраиваемый Chat Widget

Пример интеграции виджета чата на внешний сайт

📖 Описание

Этот виджет предоставляет полнофункциональную систему онлайн-чата для интеграции на внешние веб-сайты. Виджет поддерживает авторизацию посетителей, отправку сообщений в реальном времени, загрузку файлов, систему жалоб и оценок качества обслуживания.

🔧 Быстрое подключение

Скопируйте и вставьте следующий код перед закрывающим тегом </body> на вашем сайте:

<!-- Встраиваемый Chat Widget -->
<script>
  (function() {
    // Конфигурация виджета
    var config = {
      apiUrl: 'http://localhost:3004',
      theme: 'light',
      position: 'bottom-right',
      primaryColor: '#3b82f6',
      allowFileUpload: true,
      allowComplaint: true,
      allowRating: true,
      placeholder: 'Введите сообщение...',
      welcomeMessage: 'Добро пожаловать! Как могу помочь?',
      operatorName: 'Оператор поддержки'
    };
    
    // Загрузка стилей
    var link = document.createElement('link');
    link.rel = 'stylesheet';
    link.href = config.apiUrl + '/widget/chat-widget.css';
    document.head.appendChild(link);
    
    // Загрузка скрипта
    var script = document.createElement('script');
    script.src = config.apiUrl + '/widget/chat-widget.js';
    script.onload = function() {
      if (window.initChatWidget) {
        window.initChatWidget(config);
      }
    };
    document.head.appendChild(script);
  })();
</script>
💡 Важно: Замените http://localhost:3000 на реальный URL вашего API сервера.

⚙️ Параметры конфигурации

{
  "apiUrl": "http://localhost:3000",          // URL API сервера
  "theme": "light",                           // Тема: 'light' или 'dark'
  "position": "bottom-right",                 // Позиция: 'bottom-right' или 'bottom-left'
  "primaryColor": "#3b82f6",                  // Основной цвет виджета
  "allowFileUpload": true,                    // Разрешить загрузку файлов
  "allowComplaint": true,                     // Разрешить жалобы
  "allowRating": true,                        // Разрешить оценки
  "maxFileSize": 10485760,                    // Максимальный размер файла (10MB)
  "placeholder": "Введите сообщение...",      // Placeholder для поля ввода
  "welcomeMessage": "Добро пожаловать!",      // Приветственное сообщение
  "operatorName": "Оператор поддержки"        // Имя оператора по умолчанию
}

🎯 Основные возможности

💬 Чат в реальном времени

WebSocket соединение для мгновенного обмена сообщениями между посетителями и операторами.

👤 Авторизация посетителей

Автоматическая регистрация посетителей с cookies-идентификацией и полная авторизация через модальные окна.

📎 Загрузка файлов

Поддержка вложений с настраиваемыми ограничениями по размеру и типу файлов.

⭐ Система оценок

Возможность оценивать качество обслуживания операторов с комментариями.

🚩 Подача жалоб

Система жалоб на операторов с детальным описанием проблем.

🎨 Настраиваемый дизайн

Полная кастомизация внешнего вида под брендинг вашего сайта.

🔒 Профиль пользователя

Личный кабинет с просмотром профиля и возможностью выхода из системы.

🍪 Cookies-идентификация

Автоматическое сохранение сеанса пользователя между визитами на сайт.

📱 Адаптивность

Виджет автоматически адаптируется под различные размеры экранов. На мобильных устройствах окно чата разворачивается на весь экран для удобства использования.

🔗 API интеграция

Виджет использует следующие API эндпоинты:

  • POST /auth/register - Регистрация посетителей
  • POST /auth/login - Авторизация пользователей
  • GET /auth/me - Проверка токена и получение данных пользователя
  • POST /auth/logout - Выход из системы
  • POST /chat/conversations - Создание беседы
  • WebSocket /chat - Обмен сообщениями
  • POST /ratings - Отправка оценок
  • POST /complaints - Подача жалоб
  • POST /chat/conversations/:id/attachments - Загрузка файлов
